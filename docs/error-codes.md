# 错误码与排查指南

## HTTP 状态码

| 状态码 | 含义 | 处理策略 | 用户提示建议 |
|---|---|---|---|
| **200** | 成功 | 保存并交付图片 | 交付路径与实际像素尺寸、分辨率档位（1K / 4K） |
| **400** | 参数非法 | **不重试**。检查 size/quality 白名单或提示词合规性 | 提示参数错误，核对尺寸或提示词内容 |
| **401** | Key 失效 / 未授权 | **不重试**。检查 `config.json` 中对应档位（1k/4k）的 API Key | 提示 API Key 无效或过期，需更新配置 |
| **402** | 余额不足 | **不重试**。避免重复计费请求 | 提示账户余额不足，请前往服务商后台充值 |
| **404** | 路由不存在 / 未开放 | **不重试**。检查 base_url 与 endpoint | 提示当前 API 接口未开放生图能力 |
| **502 / 503 / 504** | 上游服务抖动 / 超时 | **自动重试 1~2 次**（指数退避 1s, 2s） | 若持续失败，提示上游服务暂时不可用，建议稍后重试 |
| **Network Timeout** | 网络连接超时 | **自动重试 1 次** | 提示网络波动，检查网络连通性 |

## 敏感信息防护

任何错误提示均不能包含 API Key、Authorization 头或完整鉴权 Token。
